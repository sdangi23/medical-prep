## Spaced Repetition Architecture

Every **4th day** is a dedicated **🔁 Snapshot Review Day** — no new topics. Just:
1. Re-read snapshot bullets from the prior 3 days
2. Solve targeted MCQs per reviewed topic
3. Run flashcard sprint
4. Mixed unseen MCQ marathon

**Daily routine** (3–4h split across morning/afternoon):
| Slot | Duration | Activity |
|------|----------|---------|
| Warm-up | 10–15 min | Read yesterday's snapshot OR recall 5 facts from memory |
| Theory Block(s) | 70–100 min | Structured reading of today's topic(s) — make notes |
| MCQ Drill | 40–50 min | 25–40 topic-specific PYQ questions |
| Error Review | 20 min | Annotate every wrong answer with correct concept |
| Snapshot | 15–20 min | Write/update 10-bullet summary in notes/<subject>.md |
| Flashcards | 10 min | Create 5–6 cards for hardest points of the day |

## First 7 Days — Detailed To-Do Breakdown

### Day 1 (Sep 20) — Diabetes Mellitus [~215 min]
- [ ] ☀️ Warm-up: Skim DM chapter headings in Harrison's (15 min)
- [ ] 📖 Theory Block 1: DM types (T1/T2/LADA/MODY), WHO/ADA 2023 diagnostic criteria (FPG ≥126, 2hPG ≥200, HbA1c ≥6.5%) (40 min)
- [ ] 📖 Theory Block 2: DM management — metformin first line, SGLT2i, GLP-1 RA, DPP4i, insulin types & timing (40 min)
- [ ] 📖 Theory Block 3: DKA vs HHS comparison table + DKA management protocol (fluids → insulin → K+ correction) (35 min)
- [ ] ✏️ MCQ Drill: 30 DM-focused PYQ questions (45 min)
- [ ] 🔍 Error Review: One-line concept fix per wrong answer (20 min)
- [ ] 📌 Snapshot: 10-bullet DM summary → notes/medicine.md (DKA/HHS table + insulin types + criteria) (20 min)
- [ ] 🃏 Flashcards: 6 cards — DM diagnostic criteria, DKA vs HHS, insulin types, SGLT2i, K+ protocol, HbA1c targets (10 min)

### Day 2 (Sep 21) — Liver Disease & Jaundice [~210 min]
- [ ] ☀️ Warm-up: Read yesterday's DM snapshot in notes/medicine.md (10 min)
- [ ] 📖 Theory Block 1: Jaundice classification (pre/hepatic/post), bilirubin metabolism, LFT patterns per type (35 min)
- [ ] 📖 Theory Block 2: Viral hepatitis — Hep A/B/C/D/E routes, serology markers (HBsAg, anti-HBs, HBeAg, anti-HBc IgM/IgG, anti-HCV), DAAs/tenofovir (45 min)
- [ ] 📖 Theory Block 3: Cirrhosis — Child-Pugh score (5 parameters), complications (ascites, SBP, HRS, HE, HCC) (35 min)
- [ ] ✏️ MCQ Drill: 30 Liver/Jaundice PYQ questions (45 min)
- [ ] 🔍 Error Review: Hepatitis serology #1 confusion zone (20 min)
- [ ] 📌 Snapshot: Hepatitis serology table + Child-Pugh → notes/medicine.md (15 min)
- [ ] 🃏 Flashcards: 5 cards — Hep B window period, Child-Pugh, SBP criteria, jaundice LFT, HBV vs HCV Rx (10 min)

### Day 3 (Sep 22) — Anaemia & Haematology [~205 min]
- [ ] ☀️ Warm-up: Recall DM diagnostic criteria numbers + Hepatitis B window period (10 min)
- [ ] 📖 Theory Block 1: WHO Hb cutoffs, morphological + etiological classification, IDA workup (serum ferritin, TIBC, iron, smear) (35 min)
- [ ] 📖 Theory Block 2: Megaloblastic (B12 vs folate), SCD/subacute combined degeneration, sideroblastic (35 min)
- [ ] 📖 Theory Block 3: Haemolytic anaemias — intravascular vs extravascular, sickle cell crisis types, thalassemia genetics, G6PD triggers (35 min)

- [ ] 📌 Snapshot: Anaemia comparison table (MCV/MCH/ferritin/TIBC/smear/Rx) → notes/medicine.md (20 min)
- [ ] 🃏 Flashcards: 5 cards — IDA vs thal trait, B12 vs folate, sickle cell crises, G6PD triggers, WHO Hb cutoffs (10 min)

### Day 4 (Sep 23) — 🔁 SNAPSHOT REVIEW DAY (Days 1–3)

- [ ] 📌 Block 2 — Liver: Re-read hepatitis serology table → solve 15 Liver MCQs (30 min)
- [ ] 📌 Block 3 — Anaemia: Re-read anaemia comparison table → solve 15 Anaemia MCQs (30 min)

### Day 5 (Sep 24) — Neoplasia & Tumor Markers [~215 min]
- [ ] ☀️ Warm-up: 5 random flashcards from Days 1–3 (no notes) (10 min)
- [ ] 📖 Theory Block 1: Benign vs malignant 8 differences, metastasis pathways (lymphatic/haematogenous/transcoelomic) (40 min)
- [ ] 📖 Theory Block 2: Carcinogenesis — chemical, physical, viral (HPV/HBV/EBV/HTLV-1) + oncogenes vs TSG (p53, RB, BRCA) (35 min)
- [ ] 📖 Theory Block 3: Tumor markers full table — AFP, CEA, CA-125, PSA, CA-19-9, β-HCG, LDH, NSE, Calcitonin, S-100 (25 min)
- [ ] ✏️ MCQ Drill: 40 Neoplasia/Tumor marker PYQ questions (50 min)
- [ ] 🔍 Error Review: Markers shared between cancers (β-HCG in choriocarcinoma AND testis) (20 min)
- [ ] 📌 Snapshot: Tumor markers table + 8 differences → notes/pathology.md (20 min)
- [ ] 🃏 Flashcards: 6 cards — AFP/CEA/CA-125/PSA, β-HCG uses, viral carcinogens, metastasis routes (10 min)

### Day 6 (Sep 25) — Viral Infections & Exanthemata [~215 min]
- [ ] ☀️ Warm-up: Tumor markers recall — name the cancer for AFP, CEA, PSA, CA-125, Calcitonin (10 min)
- [ ] 📖 Theory Block 1: Exanthemata table — measles (Koplik/3Cs), rubella (Forchheimer/CRS), chickenpox vs smallpox (centripetal vs centrifugal), roseola (fever breaks when rash appears) (45 min)
- [ ] 📖 Theory Block 2: Dengue (NS1 days 1–5, IgM day 5+, tourniquet test, warning signs, dengue shock), Chikungunya vs Zika (30 min)
- [ ] 📖 Theory Block 3: HIV — WHO staging 1–4, CD4 thresholds (ART <500, PCP prophylaxis <200, MAC <50), AIDS-defining illnesses, ART first line (TDF+3TC+DTG), PMTCT (35 min)
- [ ] ✏️ MCQ Drill: 40 Viral infection PYQ questions (50 min)
- [ ] 🔍 Error Review: Chickenpox vs smallpox is most tested confusion (20 min)
- [ ] 📌 Snapshot: Exanthemata comparison table + HIV staging → notes/microbiology.md (20 min)
- [ ] 🃏 Flashcards: 6 cards — Koplik vs Forchheimer, dengue timing, HIV CD4 thresholds, dengue warning signs, ART first line (10 min)

### Day 7 (Sep 26) — Neurology [~230 min]
- [ ] ☀️ Warm-up: Read Neoplasia + Viral snapshots (5 min each) (10 min)
- [ ] 📖 Theory Block 1: Stroke — TOAST classification, FAST, NIHSS, thrombolysis window 4.5h, tPA contraindications, lacunar syndromes (40 min)
- [ ] 📖 Theory Block 2: Epilepsy — ILAE 2017 classification, drug per seizure type (absence→ethosuximide, GTCS→valproate, focal→carbamazepine), status epilepticus protocol (35 min)
- [ ] 📖 Theory Block 3: Meningitis CSF table — bacterial/viral/TB/fungal (appearance, WBC, protein, glucose, special test), empirical Rx by age, India ink for Cryptococcus (30 min)
- [ ] ✏️ MCQ Drill: 35 Neurology PYQ questions (45 min)
- [ ] 🔍 Error Review: CSF interpretation + thrombolysis criteria most missed (20 min)
- [ ] 📌 Snapshot: CSF analysis table + stroke algorithm → notes/medicine.md (20 min)
- [ ] 🃏 Flashcards: 6 cards — CSF bacterial meningitis, thrombolysis, absence epilepsy drug, SE protocol, stroke syndromes, TB meningitis CSF (10 min)
- [ ] 📌 **Weekly Wrap-up**: Read ALL 7-day snapshots back-to-back (25 min)
